# sidpms

SID 프로젝트 관리 웹페이지 (단일 HTML 파일).

## 기능
- 대시보드: 월간/주간/일간 타임라인·캘린더, 프로젝트 기간 바 표시
- 프로젝트 상세: 프로젝트 상태(진행도, D-day), 일정 캘린더, 일일 진행일지
- 일지 카카오톡 "나에게 보내기" 전송
- 설정: 테마 색상 8종, 워크스페이스 이름, 주 시작 요일
- 반응형 레이아웃 (데스크톱/모바일)

## Supabase 연결 (DB 저장)
1. Supabase 프로젝트의 SQL Editor에서 `supabase.sql`을 실행합니다.
2. 페이지의 Settings > "데이터베이스 연결"에 Project URL과 anon public key를 입력하고 `연결 저장`을 누릅니다. 값은 해당 브라우저(localStorage)에만 저장되며 저장소에 포함되지 않습니다.
3. 연결하면 프로젝트, 진행도, 일지, 일정, 설정이 모두 Supabase `pms_docs` 테이블에 저장되고, 4초마다 변경 사항을 불러옵니다.

> 현재 정책은 anon key를 아는 누구나 읽고 쓸 수 있습니다. 로그인 기능을 붙이기 전에는 URL과 키를 공개하지 마세요.

## 사용
`index.html`을 브라우저에서 열면 됩니다. 클라우드 저장(db)과 카카오톡 전송은 Claude 아티팩트 환경에서만 동작하며, 그 외 환경에서는 현재 세션에만 저장됩니다.
